# Base de Vacances

Un domaine de vacances en 3D à explorer en vue à la première personne (three.js, un seul fichier `index.html`).

- 🎿 **Ski** : télésiège jusqu'au sommet, descente en slalom chronométrée
- 🚙 **4x4** : circuit tout-terrain, tours chronométrés
- 🚤 **Bateau** : hors-bord autour des bouées depuis le ponton
- 🌲 **Acrobranche** : trois parcours dans les arbres et trois grandes tyroliennes

**Jouer en ligne :** https://yifeng-lin.github.io/BaseDeVacance/

Commandes : souris pour regarder · `ZQSD`/`WASD` · `Maj` courir · `Espace` sauter / frein à main · `E` interagir · `1…5` téléportation · `M` son · `Échap` libérer la souris.
